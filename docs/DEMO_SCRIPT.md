**1:45–2:25 — Generalized research, graceful failure**
Try WIPRO or TCS for the reviewed November 2026 snapshot; both have annual-report and transcript notes. Use Fetch latest company PDFs to show the generic discovery path. If the provider rejects access, say so and upload a company-issued text PDF. Any valid NSE ticker uses the same discovery and retrieval code; source availability is a dependency, not a guarantee.

**2:25–3:00 — Explain the engineering choices**
Default flow costs zero model tokens. Optional source-grounded synthesis needs a session-only Groq key. Show evidence export. Explain the deliberate omissions: no unverified universal ratio extraction, no news-driven research, no OCR and no closed-tab notifications. Conclude with source health, async extraction and evaluated financial reconciliation as next steps.
